# PHP 7.3

## 中文

此目录用于 PHP 7.3 系列的源码安全回补。当前只有 **[7.3.4 / Windows x64 / NTS / VC15](7.3.4/README.md)**，属于实验性、非官方移植候选版。

补丁按精确的 PHP 源码版本制作。不要把 7.3.4 的更改文件、DLL 或安装脚本直接当作 7.3.32 / 7.3.33 等版本的补丁。未来版本应放到独立目录，并记录各自构建、哈希和验证结果。

## English

This directory groups PHP 7.3 source security backports. The only target currently supplied is **[7.3.4 / Windows x64 / NTS / VC15](7.3.4/README.md)**, an experimental unofficial source-port candidate.

The patch targets an exact source release. Do not treat the 7.3.4 replacement files, DLLs or installer as a patch for 7.3.32, 7.3.33 or other releases. Future targets belong in separate version directories with their own build records, hashes and validation.
